LISTAS
Em listas sempre usamos List e colocamos o tipo entre <>, sempre declara ela e depois usa como new. 
    List<string> | List<int>
    List<int> numeros;
    numeros = new List<int>();

    ADD em List
        List<string> palavras = new List<string>();

        palavras.Add("Telefone");
        palavras.Add("Teclado);

    COUNT - Tamanho da lista
        Console.WriteLine(palavras.Count);
    
    ForEach - Percorrer listas
        foreach (string palavra in palavras)
        {
            Console.WriteLine(palavra);
        }
    
    Acessamdo Indices 
        for (int i=0; i < palavras.Count; i++)
        {
            Console.WriteLine(palavras[i]);
        }


FUNÇÃO

    A estrutura geral de uma definição de função em C# é:
    Não há necessidade ter parametros. 

    tipoDeRetorno NomeFuncao(tipoDeDados parametro1, tipoDeDados parametro2)
    {
        // corpo_da_funcao
    }

    Se não tem retorno se usa VOID ex.:
    void ExibirMensagemPessoal(string nomeUsuario)
    {
        Console.WriteLine($"Olá {nomeUsuario}");
    }

    Retorno usa String ou Int, Double etc...

    Use static para todas as suas funções até começarmos a escrever classes.
    static int SomarNumeros(int primeiro, int segundo)
    {
        int soma = primeiro + segundo;
        return soma;
    }
